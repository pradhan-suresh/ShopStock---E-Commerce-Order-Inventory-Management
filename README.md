# ShopStock – E-Commerce Order & Inventory Management System

## Project Overview
ShopStock is a full-stack web application developed using Python and Flask to simplify e-commerce operations through efficient product management, order processing, and inventory tracking. The application provides an interactive admin dashboard to monitor products, manage orders, track stock availability, and maintain inventory records.

## Key Features
- **Product Management:** Add, update, view, and delete product details.
- **Order Management:** Manage customer orders and track order information.
- **Inventory Management:** Monitor stock levels and maintain inventory records.
- **Automated Stock Updates:** Update product quantities based on order processing.
- **Admin Dashboard:** Interactive dashboard for managing products, orders, and inventory.
- **Database Integration:** Store and manage application data using SQLite and Flask-SQLAlchemy.
- **CRUD Operations:** Implement Create, Read, Update, and Delete functionalities.
